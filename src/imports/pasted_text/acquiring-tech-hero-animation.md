Create a premium cinematic animated hero visual for the Acquiring Technology website.

Use the uploaded reference image only as inspiration for the visual language: a glowing intelligent sphere with flowing data/energy paths. Do NOT copy the OpenAI logo, Astra branding, GPT text, or any text from the reference.

BRAND:
Company: Acquiring Technology
Focus: Software Engineering + Artificial Intelligence + Digital Transformation
Primary brand color:
#B0182A

CONCEPT:
Create an “AI Seed” animation that represents an idea becoming intelligent technology.

The animation should feel:
- Premium
- Cinematic
- Intelligent
- Technical
- Minimal
- Enterprise-grade
- Slow and sophisticated
- High-end technology company aesthetic

Do NOT make it look like a gaming website, crypto website, or generic AI landing page.

ANIMATION STORY:

1. INITIAL STATE
Start with an almost-black background (#08080A).

The screen should initially feel calm and nearly empty.

A very small glowing red point appears near the center.

The point represents the beginning of an idea.

2. AI SEED
Over approximately 2 seconds, tiny particles and extremely thin data lines slowly move toward the central point.

The particles should move smoothly and organically.

Use very subtle red illumination based on:
#B0182A

Avoid excessive glow.

3. SEED FORMATION
The central point slowly expands into a small intelligent “seed” or core.

The seed should look like a sophisticated digital energy core rather than a literal plant seed.

Use:
- Fine particle structure
- Thin technical lines
- Subtle red light
- Very subtle white highlights
- Transparent layered geometry

4. LOGO REVEAL
After the seed stabilizes, gradually reveal the actual Acquiring Technology logo in the center.

The logo should appear using:
- Opacity 0 → 100%
- Scale 96% → 100%
- Very subtle blur → sharp
- Soft red illumination

Do NOT distort the logo.

Do NOT generate a fake replacement logo.

Use the actual uploaded Acquiring Technology logo asset if available.

5. DATA ORBIT
Once the logo is visible, create 2–4 extremely thin flowing data paths around the logo.

The paths should slowly orbit around the central seed.

They should feel like:
DATA → AI → INTELLIGENCE → ACTION

Use restrained red highlights with neutral white/gray supporting lines.

The motion should be very slow.

6. INTELLIGENCE ACTIVATION
Occasionally, a small particle travels along one of the data paths.

When it reaches the central seed:
- briefly increase the seed brightness
- activate a tiny red highlight
- create a very subtle ripple
- return smoothly to the normal state

This should happen slowly and naturally.

Do NOT make it flashy.

7. CONTINUOUS LOOP
The complete animation should loop seamlessly.

The loop should feel continuous and never obviously restart.

Target duration:
12–18 seconds.

Animation speed:
SLOW.

Use smooth cinematic easing.

No bouncing.
No elastic animation.
No sudden movements.

VISUAL DESIGN:

Background:
#08080A / near black

Primary accent:
#B0182A

Supporting colors:
#FFFFFF
#E7E7E8
#77777D
very subtle dark-red gradients

Keep the composition mostly dark.

Red should be an accent, not the dominant color.

COMPOSITION:

Desktop:
1440 × 900

Place the intelligent seed/logo slightly right of center so the left side has enough negative space for hero copy.

Left side:
Hero headline and CTA.

Right side:
Animated AI seed/logo visual.

The visual should occupy approximately 45–50% of the hero.

MOTION DEPTH:

Use multiple depth layers:

Background:
Very slow particle movement.

Middle:
Slow orbital data paths.

Foreground:
Small particles moving along selected paths.

Central:
Stable intelligent seed and logo.

Add extremely subtle mouse-parallax interaction on desktop.

Mouse movement should shift the background and orbit layers only 3–8px.

The central logo should remain mostly stable.

MOBILE:

On mobile, simplify the animation.

Reduce:
- particle count
- orbit complexity
- parallax
- glow
- movement

Keep the central seed/logo clear and lightweight.

PERFORMANCE:

Design the animation so it can realistically be implemented on a production website.

Prefer:
- CSS transforms
- opacity
- SVG paths
- lightweight particles
- requestAnimationFrame where required

Avoid:
- heavy 3D
- large video backgrounds
- excessive blur
- thousands of particles
- expensive WebGL effects

TARGET EXPERIENCE:

The visitor should feel:

“Something intelligent is forming.”

Then:

“An idea is becoming technology.”

Then:

“Acquiring Technology builds intelligent software.”

The animation must support the brand story instead of distracting from the headline.

IMPORTANT:
Do not animate every element.

The motion must feel intentional, slow, precise and premium.

The final result should look like the visual identity of a world-class software engineering and AI company.
