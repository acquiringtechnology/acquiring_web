# Acquiring Technology (acq)

Elite Software Engineering, AI Solutions, and Technology Acquisitions website built with Next.js 15 (App Router), React 19, and Tailwind CSS v4.

## Features
- **Next.js 15 App Router**: High-performance SSR and static prerendering.
- **Animated Company Logo Reveal**: Geometric assembly of the Acquiring Technology brand mark with smooth wordmark reveal.
- **Lenis Momentum Smooth Scrolling**: Butter-smooth inertial scrolling and quartic ease-out anchor transitions.
- **Tailwind CSS v4**: PostCSS integration with custom design tokens and keyframe animations.
- **Complete Suite of Sections**: Services, Software Engineering, AI Solutions, Process, Tech Stack, Industries, Why Us, Case Studies, About, and Interactive Project Intake Form.

## Getting Started
```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view in the browser.

## Production Build
```bash
npm run build
npm start
```
